## Step 3: Add Credentials to Railway

1. Go to railway.app
2. Your project → Settings → Variables
3. Click "New Variable" and add:

   ANGEL_ONE_API_KEY = [paste your API key - keep secret!]
   ANGEL_ONE_CLIENT_ID = [paste your Client ID]
   ANGEL_ONE_PASSWORD = [paste your PIN]

4. Never share these credentials!
5. Only add them in Railway, never on GitHub
6. Click Save
